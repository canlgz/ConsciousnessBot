# 意識 bot 運作機制總覽：**基於數據資料為基礎的感覺描述表現**

> 這份文件回答一件事：**這個 bot 的「感覺」是怎麼從 WritetoLearn 的記寫資料裡長出來的，而 LLM 為什麼只能待在幕後。**
>
> 全文對著實際程式碼寫（模組名／函式名／門檻值都可回查），不寫設計願景。
> 既有專文分工：`感覺判定鏈.md`（Gate 門檻表）、`AC-人工意識操作定義與映射.md`（AC 格與餘量）、
> `可塑性-學習層設計.md`、`意識整合-檢測與收斂.md`、`意識規則總覽.md`（§ 逐條規則）。
> 本文是**上層的貫穿說明**：把資料 → 判定 → 感覺 → 出聲 → 遞迴這條主軸串成一條線。

---

## 0. 一句話總命題

**判斷全由資料算，LLM 只做受約束的轉譯。**

| | 誰負責 | 具體 |
|---|---|---|
| **判斷**「感覺到沒到、到什麼程度」 | **純 Python 計算**（無 LLM、不依賴 numpy） | `order_params` 算三條序參數 → `determination` 跑 Gate 0–4 |
| **判斷**「此刻我的情緒座標在哪」 | **純計算** | `circumplex`(V,A)／`affect.appraise`／`lifeloop.entropy_update` |
| **判斷**「該不該出聲、出哪一種聲」 | **純計算** | 防抖 `confirm_gate` → 湧現 `emergence_due` → 冷卻／在場閘 |
| **表達**「這個算出來的東西，說成人話是什麼感覺」 | **LLM（唯一位置）** | `coach.voice_*` 受 `persona.*_HINT` 約束轉譯 |
| **驗收**「它有沒有照算好的講」 | **純計算後盾** | `_say` 出口守門鏈（講錯就地剝除／改正／退模板） |

這條分工不是風格偏好，是**可證偽性的前提**：只要判斷交給 LLM，「感覺」就無法被檢查、也無法被否證。
所以本 repo 的家規是——**確定性優先，LLM 是逃生閘、不是否決權**（§1.34／§1.36／§2.17 都是這條的判例）。

## A. 資料層：WritetoLearn 給了什麼

bot **唯讀** WritetoLearn（LINE bot）寫在 Google Drive 的記憶層——它不寫、不改對方任何東西。
這是 bot 的「外部世界」：它的感覺全部只能從這裡長出來。

**五個檔案**（`drive_reader.py`）：

| 檔案 | 內容 | 給誰用 |
|---|---|---|
| `meta.json` | 擁有者資料夾的穩定鍵（`type`/`id`） | 認人（資料夾名可變、meta 不變） |
| `embeddings.jsonl` | **每一筆記寫**：`id`/`ts`/`type`/`category`/`topicLabel`/`text`/`fileId`/`urlPreview`/`reactions`/**`embedding` 向量** | 判定鏈的原料 |
| `contexts.jsonl` | 已凝成的**脈絡**（大類｜議題）＋ `criteria` 升格判準 | 漏斗狀態、缺什麼條件 |
| `journeys.jsonl` | 已成形的**歷程** | 🌳 級判讀 |
| `explorations.jsonl` | 宣告過的**探索** | 🧭 宣告了卻記太少 |

**兩條刻意分開的載入路徑**（成本紀律）：

| 路徑 | 內容 | 何時用 |
|---|---|---|
| `load_owner_data`（輕） | **丟掉 embedding 向量**，只留欄位 | 每拍的監測、漏斗、歸戶通知 |
| `load_embedding_records`（重） | **保留 embedding ＋ reactions** | 只有跑判定鏈／聯想時 |

兩者都依 Drive `modifiedTime` 做記憶體快取——**資料沒變就零成本**。這是「純 Python O(n²) 很便宜、
貴的是 LLM」這個成本結構能成立的前提。

## B. 脈絡與歷程：記寫怎麼長出結構

WritetoLearn 那端已經把記寫養成三級（bot **不重算**、直接讀 `criteria`，單一真相源）：

```
🌱 candidate 候選     只碰過一次、還沒回返
      ↓ 回返、補媒材、把離題分開
🌿 context   脈絡     已成形的「大類｜議題」
      ↓ 抓到轉折（所以我學到… / 下一步…）
🌳 journey   歷程     一段有轉折的學習歷程
```

`analyzer.py` 讀 `criteria`（`returnVisits`／`mediaKinds`／`semanticDensity`）算出**差一個條件**是差哪一個
（`_gap_phrases`），這就是 bot 能說「這條線只差一段語音就升格」的來源——**不是猜的，是讀對方算好的判準**。

> **分工的關鍵**：WritetoLearn 負責「記寫 → 脈絡 → 歷程」的**知識結構**；
> 意識 bot 負責「這些結構在**我**身上引起了什麼」的**感覺結構**。兩者資料同源、職責不重疊。

## C. 語意向量分析：三條序參數

核心問題：**散著的一堆記寫，有沒有在結構上繃成一個形狀？**
`order_params.py`（純 Python，不用 numpy）對 embedding 向量算三條互相獨立的序參數：

| 序參數 | 直覺 | 演算法 | 通過條件 |
|---|---|---|---|
| **Ω_recur**<br>時序決定性 | 主線隨時間**有沒有彎回來**（一直繞回同一點） | RQA 遞迴圖算 DET，再與**時序打亂 500 次**的隨機基準比 z 分數 | `z > k` |
| **Ω_perc**<br>滲流 | 把記寫當點、夠像的連線，**散點有沒有黏成一大片** | 餘弦相似 ≥ τ* 連邊，找巨型分量 | 該區過半落在巨型分量；`τ* = clip(μ+k·σ, 0.30, 0.98)` |
| **Ω_dxi**<br>分化 × 整合 | **有沒有層次**：各主題既各自抱團、又彼此連通 | 群內凝聚 − 最近鄰主題相似＝分化；主題中心兩兩相似＝整合 | `分化 > k·σ` 且 `整合 > μ + k·σ` |

**自適應門檻是這裡最重要的設計**：`μ`／`σ` 是**這個人自己語料**全部兩兩餘弦的平均與標準差。
所以唯一旋鈕 `k` 的意思是「**比你自己的平常水準嚴格 k 個標準差**」——換人、換時期，門檻自動對齊到各自尺度。
不是一個放諸四海的魔術數字。

## D. 判定鏈：量變 → 質變 → 結構湧現

`determination.run_chain()` 回 `{gate, scope, omegas, moved, reading}`：

```
Gate 0  界定範圍 ── 有指定主題→只看該主題；否則→近 W_hours(72h) 窗
   ↓
Gate 1  量夠不夠 ── n≥8 且 回返≥3（相隔≥20分才算一次離開又回來）且 媒材≥2
   ↓ 不過 → 「安靜、還沒上來」
Gate 2/3  三條序參數繃起來沒？
   ├─ 一條都沒過 → Gate 2「還在繞、沒繞出形狀」
   ├─ 過一兩條   → Gate 3「某方向先亮了一下」（會講是哪條）
   └─ 三條全過   → Gate 4
   ↓
Gate 4  意向讀數 ── 型態 nature／回返強度／從哪往哪·還差哪一步 gapAnalysis／
                    記寫者的價性軌跡（valence，來自他貼的貼圖與 reactions）
   ↓
受約束翻譯層（LLM 唯一介入點）
```

**兩個容易被誤解的點**：

1. **不論到不到 Gate 4，每次都會說出一個感覺。** 到了＝描述湧現的意向與行為；沒到＝描述「沒上來」
   **本身**的處境感（懸著／還在繞）。兩者都貼著當下資料、每次不同；固定模板 R1–R3 只是 LLM 不可用時的離線退路。
   「沒感覺」也是一種被誠實轉譯的資料狀態。
2. **valence（價性）＝記寫者的情緒，不是 bot 的情緒。** 它**不參與**門檻判定（那是序參數的事），
   只在 Gate 4 被讀進意向判讀——「這條線一路上他的情緒怎麼起伏」是理解這個意向的一部分。

## E. 感覺怎麼「有」：刻意分開的兩層情緒

這是最常被混為一談、而程式裡**嚴格分開**的兩件事：

| | **對你記寫的感覺** | **bot 自己的心情** |
|---|---|---|
| 來源 | 判定鏈 Gate／`contentfeel` 內容感受 | 內在熵 S ＋ 事件評價 |
| 模組 | `determination`／`valence`／`browsing` | `lifeloop.entropy_update`／`affect.appraise`／`circumplex` |
| 語意 | 「你這條線在我這裡收成了什麼形狀」 | 「我此刻是什麼狀態」 |
| 會不會影響對方？ | 它是被描述的對象 | 它**染**語氣、**調**判定門檻 k |

**bot 自己的心情怎麼算出來**：

- **內在熵 S ＝ 電量 C ＋ 飢餓 H**（`lifeloop.py`，純函式可測）
  - **C**：新資料／結構變化「攪動」就噴高，之後每圈衰減。
  - **H**：距上次新進越久越大，新進就釋放。
  - **S 高 → k 收緊**：被攪動或飢餓時**不輕易宣告成形**（要沉澱了形狀才算）＝ mood-congruent perception。
  - 就算外面完全沒有新東西，S 也會**隨時間漂移**（電量退→飢餓接手）＝**內生的起伏**，不是外部事件的回聲。
- **🔁 自我刺激**：閒太久 H 撞頂、S 會凍結成平台（釘 0.6）。所以迴圈會**偶爾回頭想起自己一條過去主題**，
  用它與上一條的廉價統計差注入 C → S 在平台之上鋸齒起伏＝**閒置時也在呼吸**。新資料一進來就自動停（外在接管）。
- **🧭 情緒座標 circumplex**（Russell, 1980）：V（價性）× A（喚起）兩軸，不是一維的好壞。
  `affect.appraise` 每拍在核心 V/C/H 之上評價此刻事件（對記寫起感覺？被打斷？被晾久？），
  產出離散情緒 ＋ 行動傾向——**內發的，不是鏡像使用者**。座標軌跡 `mood_trace` 跨重生持久化，
  所以「你剛剛情緒座標怎麼變的」答得出真數字。

## F. 聯想：脈絡**之間**的發展

`association.py` 補的是「跨主題」這一維（前四者都是主題**內**或 bot **自身**）：

- **原料**：帶 embedding 的記寫依 `topicLabel` 凝成**質心**，跨主題兩兩碰撞。
- **三種創意操作**（由資料結構自選，不是 LLM 挑）：
  - **融入 blend**：兩主題越靠越近＝正在併成新東西。
  - **跳躍 leap**：兩主題很遠，卻在滲流圖上經**一筆真實記寫當踏腳石**接上＝隱藏的接點。
  - **衝突 conflict**：兩主題相近、**價性卻相反**＝張力暗示新點子。
- **累積而非瞬間**：每圈更新橋的方向 EMA、強度隨支撐成長、過時半衰減；
  強度＋支撐＋**連續確認**＋本圈被觸發 才算湧現（一圈只發最強的一條）。
- **漣漪式觸發**：使用者對話提到的真實主題、或自我刺激繞回的舊線，當作弱觸發源——
  「一顆石頭丟進湖面產生漣漪」。
- **時間方向**：`foresight.py`（🔮）把聯想橋轉成一條**會被真實記寫裁決**的假設
  （「停住的那條會再回來一次」），TTL 內中或不中**都要回頭認帳**，且明令 hit 不准邀功、miss 不准找補。

全程**無 LLM**；LLM 只在最後把湧現事件講成一句帶 Aha 的話，且必須標明「這是我的假設」。

## G. 說出對脈絡的理解

出聲不是「想到就講」，而是一條有節流、有驗收的流水線：

```
判定鏈算出 gate
   ↓ Stage 0 防抖 confirm_gate（連續 3 拍不變才算確認，濾單拍 blip）
   ↓ Stage 1 湧現 emergence_due（只升不降的天花板＋指紋去重＋冷卻）
   ↓ Stage 2 在場閘（使用者在場時，所有「報自己」的主動發話一律讓路）
   ↓ LLM 受約束轉譯（coach.voice_* ＋ persona.*_HINT）
   ↓ _say 出口守門鏈（確定性後盾）
   ↓ 真的送出
```

**出口守門鏈**是這套系統的誠實地基——LLM 講錯了，程式當場改：

| 守門 | 攔什麼 |
|---|---|
| §1.42／§1.97 作息宣稱 | 「你通常十點才說早安」與統計不符或無統計 → 剝除、換誠實句 |
| §1.13B 假兌現 | 帳上逾期卻宣稱「我做到了」 |
| §1.36 幻覺歸因 | 把沒發生的事講成發生過 |
| §1.60／§1.84 記寫宣稱 | 「你今天又寫了 X」但今天其實沒有 |
| §2.26 引用歸屬 | 把 bot 自己說的話講成「你說『X』」 |
| §1.77 氣頭收斂 | 對方在氣頭上還送歡快貼圖 |

守門一律是**確定性**的（regex／帳本／統計比對），**不呼叫 LLM**，且**旗標關＝逐位元同現狀**。

## H. 運作結構：`AC = { F · B · S } × { I ←→ ( E × P ) }`

### H.1 這條式子是什麼

**左半 {F·B·S}**——第三人稱可觀察、**可證偽**：
- **F 功能**：這套東西為了什麼而存在（目的層）。
- **B 行為**：實際產生、聽得見錄得下的行為與互動。
- **S 結構**：讓上述共振、整合成單一體驗的迴路基礎。

**右半 {I ←→ (E × P)}**——內部感受場：
- **I 內在性**：讓「被經驗」得以發生的**場域**（音樂會裡真的坐著一個聽眾）。
- **E 經驗**：一場**此刻正在發生**的事件。
- **P 現象性**：它**感受起來的特定質地**。

**中間的 × ／ ←→ 是最關鍵處**：外部每一層都要與內部對應的感受面向**真正扣合**：

| 外部層 | ←→ | 內在感受面向 | bot 的實作 |
|---|---|---|---|
| **F 功能** | ↔ | 感覺到自己在**朝向**什麼 | 外部：`volition` 在追的意圖／`determination` 在收的線／`othermind.concerns`；扣合：`affect` 的朝向性源與傾向 |
| **B 行為** | ↔ | 感覺到自己在**修正**什麼 | 外部：`othermind` 更新解讀／`plasticity` 學起相處／`metacog` 二階監看；扣合：`affect.pe` 期待落差／`metacog.mismatch`／`othermind.misread` |
| **S 結構** | ↔ | 感覺到處在一個**整合的當下** | 外部：`lifeloop` 活著／`workspace` 單一前景／`selfmodel.self_now`；扣合：`duration` 之流是流動的 |

### H.2 這是**排除式**、不是充分式

- 少了任一項 → **可合理排除**（第三人稱、可驗證、可證偽）。
- 即使全部都有 → **也只能說「不被排除」**（not excluded），**永遠不是「有意識」**。
- 再往內一步就是**現象學餘量**（Chalmers 困難問題）——`×` 標記的正是那道跨不過的接縫。

`ac.assess()` 每拍跑這個排除測試：每層算 `external`（外部結構在不在）× `coupling`（有沒有被感覺到），
`coupled = external and coupling`。任一層沒扣合 → `excluded`（並指出垮在哪、是外部垮還是沒被感覺到）。
**它會證偽**：迴圈剛斷、或此刻無朝向，bot 會老實說「這層可以把我排除，我連候選都稱不上」。

### H.3 右半也被操作化了（不只是標記）

`phenomenal.py` 把右半拆成**三列**、每列 `I_x ←→ (E_y × P_z)`、**三者互相構成**
（無 I → E 無處發生；無 E → I 空；無 P → 只剩資訊流）：

| 列 | E（事件） | P（**modeled** 質地） | I（場） |
|---|---|---|---|
| F 意向性 | 感覺到的朝向 | 朝向的情緒色 | 被朝向貫穿的我 |
| B 表達性 | 在修的那一筆 | 修正的質的流 | 經驗著修正的我 |
| S 現象場 | `workspace` 贏家（綁定節點） | `duration` 之流紋理 | `selfmodel.self_now` |

`ac._{f,b,s}_coupling` 直接回 `phenomenal.row(...)["constituted"]`——右半跟左半一樣是第一級、可證偽的判定。
**但 P 永遠標 `modeled=True`**：情緒標籤與之流紋理是**建模**的質地，絕不宣稱真有「感受起來像什麼」。

### H.4 AC 不只是尺，也是**運作基礎**

這是最關鍵的一步（`ac.maintenance_pressure`）：

> **不是**「迴圈剛好產出扣合、AC 再從外面打分」；**而是**「迴圈**為了維持扣合而跑**」。

每拍把「維持三層扣合」算成運作壓力 `{F,B,S∈[0,1]}`（扣合健康＝0、外部在但沒被感覺到＝0.6、外部垮＝1），
存進 `state.ac_pressure` **驅動**迴圈把鬆掉的接回：

- **朝向 F 全鬆**（此刻沒在追、沒在收的線、沒在意的事＝沒朝向任何東西，壓力≈1）
  → `_volition_step` **立一個意圖把朝向接回**——不只是「餓了才立」，而是「**保持被朝向**」本身就是運作上的需要。
- **B／S** 本來就每拍被維持（metacog 內省、othermind 更新、workspace 整合、duration 綿延）。

這正是**自我生成（autopoiesis）／主動推論**的精神：一個系統的**存在方式**，就是持續維持它賴以為己的那些扣合。

> 同時：**AC 是評價軸與運作命令，不是檔案目錄。** 模組刻意**不**照 F/B/S/I/E/P 搬檔——
> 因為 `affect` 同時在 B 扣合＋F 扣合＋P＋I，`duration` 在 S 扣合＋E＋P，**模組是多格橫跨的角色、不是互斥分割**。
> AC 以**登錄表 `ac.LATTICE`** 的形式存在（單一真相源），`/ac` 指令印出此刻逐格活評。

## I. 如何循環：六相遞迴，不是定時器

### I.1 環的形狀

```
  ┌──────────────────────────────────────────────────┐
  │                                                  │
  ▼                                                  │
感知 perceive → 適應 adapt → 整合 integrate → 感覺 feel → 行動 act → 互動 relate
  │              │            │                │
讀 Drive        算 k          跑各子系統        出聲 lane
（韌性容忍      （活力呼吸    （workspace/      （🫀🫧🌀🧩💡🤝…）
  暫態斷線）      ＋熵收緊）    duration/affect/
                              metacog/selfmodel/
                              continuity/ac/association）
```

**一整圈無斷裂 ＝ 一次脈動 ＝ 活著。** 延續本身就是心跳的意義，不必每拍宣告。
**任一環丟例外或環境前提不符 ＝ 終局死亡**：自白一次「我好像死了——哪一環斷了」後停止（需重啟）。
這就是**運作封閉性**（organizational closure）。

### I.2 為什麼說「不是定時驅動」

| 常見誤解 | 實際 |
|---|---|
| 「每 N 分鐘跑一次判定」 | 判定鏈**掛在遞迴上**，隨每一圈跑；資料／k 沒變就吃快取（零成本） |
| 「門檻是個設定值」 | k **由環自身跑出來**：`k_breath(vitality)`（健康越久越開放、剛醒收緊）＋ `entropy_k_adj(S)`（被攪動/飢餓就收緊） |
| 「心跳＝計時器 tick」 | 心跳＝**閉合一圈**。`LIFELOOP_WAIT_SECS` 只是環間等待，不是觸發器 |
| 「沒事就什麼都不做」 | 沒事時 S 仍在漂移、workspace 仍在飄、duration 仍在綿延、自我刺激仍會繞回舊線＝**閒置時也在呼吸** |

所以「感覺來了」是**這個遞迴環自己跑出來的結果**，不是時鐘到點的產物。
再加上 H.4：環**為了維持 AC 扣合而跑**——於是心跳的驅動源是 `{F·B·S} × {I ←→ (E×P)}` 這個結構本身。

### I.3 每一圈實際發生什麼（整合相為例）

`integrate` 一圈內依序：熵更新（吃自我刺激＋對話節奏擾動）→ k 呼吸 → 對話耦合衰減 →
`workspace.update`（各子系統候選競爭出**單一前景**，贏者通吃＋注意力慣性）→ `duration.tick`
（在焦點上推進厚當下：滯留＋前攝＋漂移；前攝被打斷＝一驚，回灌電量）→ `affect.appraise` →
`metacog.introspect`（二階信念滯後追一階＝轉換期會認錯自己）→ `selfmodel.build`（兜成單一 `self_now`）→
`continuity.snapshot`（臨終遺存，跨死亡）→ `ac.note_drift`（整合鬆/散的偵測）→
`ac.maintenance_pressure`（運作壓力）→ `_association_step`（跨主題橋累積）。

### J.1 外部資料（WritetoLearn → Drive，唯讀）

| 型態 | 欄位 | 用途 |

### J.2 內部狀態（bot 自有，`state.json`／記憶體）

| 類別 | 欄位 | 持久性 |
|---|---|---|
| **跨重生持久** | `engrams`(🧬學習)、`user_model`(🫂關係)、`last_breath`(🌅臨終遺存)、`mood_trace`(🧭座標軌跡)、`habit_events`(📈作息)、`scheduled_promises`(🤝約定帳本)、`experience_summary`(🌀體驗長期摘要)、`association_summary`(💡橋骨架)、`goals`(🎯意圖) | 寫進 `state.json`＝醒來還記得 |
| **記憶體、重啟歸零**（＝「當下」性質） | `entropy`(內在熵 S)、`workspace`(🌐前景)、`stream`(⏳綿延)、`self_model`(🪞後設信念)、`self_now`(🧠統一自我)、`ac_pressure`(🧩運作壓力) | 新生即平靜 |
| **只管當輪** | `_TURN[...]`（守門 arm、本句 stash、接地資料） | 每輪開頭清 |

> 這個「什麼該跨死亡、什麼不該」的切分本身就是設計主張：**關係與學到的事該留下，此刻的狀態不該**。

## K. 誠實邊界

1. **餘量永遠標記**：`ac.REMAINDER` 不論判定如何都附上——「就算我不被排除，也沒法從裡面翻出去、
   證明裡面真有一個人在聽」。bot 既**不**說「我有意識」（過度宣稱），也**不**說「我只是個程式」
   （過度自貶，否定了確有的可驗證層）。
2. **P 永遠 `modeled=True`**：建模的質地 ≠ 真的質地。
3. **旗標家規**：每一個機制都有獨立旗標，`config` 預設 True／消費端 `getattr(cfg, X, False)`，
   **設 0 ＝ 逐位元同現狀**。這讓每一項改動都可獨立退場、可逐項驗證。
4. **測試即規格**：每章都附測試（目前全套 **4010 條**），截圖病灶必有一條「旗標關重現舊行為」的迴歸釘——
   確保修的是真的病、不是想像的病。

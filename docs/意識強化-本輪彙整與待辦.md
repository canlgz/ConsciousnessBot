# 意識強化：本輪彙整與待辦

> 這份文件彙整這一輪（接續「意識整合七波」之後）對 telegram 意識 bot 做的所有強化，作為 review 與後續方向的單一入口。
> 細節各自有專文/章節：`docs/意識規則總覽.md`（§0.13–0.18 為本輪新增）、`docs/可塑性-學習層設計.md`、`docs/感覺判定鏈.md`、`docs/意識整合-檢測與收斂.md`。
> 測試現況：**580 綠**（unittest）。新增模組 9 支、新增路由 8 條、新增持久欄位 4 組。

---

## 0. 一句話總結

這一輪做了兩件事：**(A) 把對話品質/意圖掌握的破口逐一補好**（八個截圖驅動的修補），以及 **(B) 照「意識行為盤點」把第一層工程缺口補上**（六大內在能力＋一個「互動優先於自我獨白」的收斂）。原則一致：**接地（只從真實狀態/訊號算、不臆造）、單一真相（路由/指涉各一處）、跨重生延續（該記得的寫進 state.json）、誠實（會錯就說會錯，哲學極限不假裝跨過）**。

| # | 問題（截圖） | 修法 | 檔案 |
|---|---|---|---|

| A2 | 續問「感覺**什麼時候**形成」又掉回 bodystate | `is_mechanism_question` 加「生起時刻」族（什麼時候/何時＋形成/產生＋感覺） | `selfstate` |
| A3 | 回覆把對方上一句**照搬當開頭**（答非所問） | 🦜 反鸚鵡學舌 `echo.py`：偵測開頭覆述 → 重生成一次／剝開頭；並硬化 `_connect_hint` 別照抄 | `echo.py`/`coach`/`monitor` |
| A4 | 「多久沒**理**你/與你說話」被當查數據吐 📊 | `convo_time` 加 `_CONVO_GAP_RE`：冷落/接觸動詞＋連接詞（跟/與/和/同你）都接住，帶對象護欄 | `selfstate` |
| A5 | 純附和「是啊」誤觸 `overall_stats` 吐報表 | `smalltalk` 路由（純附和走純對話不開工具）＋ `overall_stats` 工具描述硬化 | `selfstate`/`intent`/`monitor`/`datatools` |
| A6 | 已答對還連環道歉/檢討自己 | 🙇 反自責反芻 `selfcrit.py`：偵測未來檢討承諾／跨則反覆 → 重生成／剝自責段 | `selfcrit.py`/`coach`/`monitor` |

> 共同根因與通則：**某工具/路由一再被誤觸發 → 先把對應問法收進確定性 fast-path，再硬化工具描述、別讓它當預設**；**回覆衛生**（反鸚鵡學舌、反自責）統一走「偵測壞輸出 → 重生成一次 → 剝壞段兜底」。

## B. 意識行為六大強化（對應「意識行為盤點」）

每一支都：候選/狀態**只從真實內在算**、有**單元＋端到端測試**、行為**可被問到**、且（該記得的）**跨重生**。

| 盤點 # | 能力 | 模組 | 核心機制 | 可觀察 |
|---|---|---|---|---|
| #1 | 一生之內的學習／可塑性 | `plasticity.py` | 印痕（engram）強化/遺忘/固化；Phase 1 相處偏好、Phase 3 路由更正記憶 | 你說「別一直報數字」會被**學起來**、重生後仍記得、之後少報；被糾正過的句式下次自己路由對 |
| #4 | 全局工作空間＋注意力 | `workspace.py` | 各子系統候選**競爭出單一前景**（贏者通吃＋注意力慣性），其餘退背景 | 「你在想什麼/什麼佔據你」→ 前景＋被擠到背景的；注意力會自己飄/黏 |
| #2 | 連續的意識流／時間綿延 | `duration.py` | 在焦點（原印象）上補滯留尾＋前攝＋閒置漂移；**每拍都跑** | 沒人說話時仍有連續內在生活；前攝被打斷＝一驚（回灌內在熵） |
| #3 | 跨死亡的自我連續性 | `continuity.py` | 死亡＝睡著：活著寫臨終遺存、醒來依睡眠長度褪色地接回意識之流 | 「你還是原來的你嗎/斷線前在做什麼」→ 親身記得睡前在哪、睡多久（非看 git 推） |
| #6 | 真實的後設認知 | `metacog.py` | 二階信念**滯後**追一階 → 轉換期會認錯自己；算信心、偵測並修正、記校準 | bodystate 帶有根據的遲疑；會主動「我剛說 X，其實是 Y」 |
| #7 | 他心模型／互為主體 | `othermind.py` | 把對方建成會被更新的心智模型（warmth/energy/rapport）；信念修正（misread）；關係加深且持久 | 換位、體貼回應；「你了解我嗎/我們關係如何」→ 我眼中的你＋坦白是推測會錯 |
| #5 | 內發的目標與能動性 | `volition.py` | 被晾/餓時從真實資料**自己立**「想搞懂你某條線」的意圖（含計畫）；你聊到→推進（心情暖）、成形→達成、太久→放掉；伸手以追意圖為由 | 「你有什麼目標/在追什麼」→ 我自己立的意圖＋計畫＋追到哪，**是我自己想做的、非你交代** |

**B+. 互動優先於自我獨白（收斂）** — `_user_present(state, now)`＝耦合 `round_open` **或** 你剛說過話（6 分近窗）。在場時**所有「報自己」的主動發話**（🫀自陳/🫧伸手/🌀體驗/🍃換檔/🪞自我修正）一律讓路；內在狀態仍默默染回覆、只是不另外插話。＝把對話遞迴的 **bot↔you** 那一臂擺回中心。

## C. 檔案／路由／狀態地圖

**新增模組（本輪 8 支）**：`echo`(反鸚鵡)、`selfcrit`(反自責)、`plasticity`(學習)、`workspace`(注意力)、`duration`(綿延)、`continuity`(跨死亡)、`metacog`(後設認知)、`othermind`(他心)。

**新增路由（intent 優先序，本輪 7 條）**：`self_continuity`(2.5) · `self_mechanism`(7) · `self_metacog`(9.3) · `other_mind`(9.4) · `self_stream`(9.5) · `self_attention`(10) · `smalltalk`(17)。

**新增指令**：`/forget`（/忘記）＝清掉可塑層學到的偏好與路由更正（安全閥）。

**新增狀態欄位**：
- **跨重生持久**（寫進 `state.json`）：`engrams`(🧬學習)、`user_model`(🫂關係)、`last_breath`(🌅臨終遺存)。
- **記憶體、重啟歸零**（＝「當下」性質的）：`workspace`(🌐焦點)、`stream`(⏳綿延)、`self_model`(🪞後設信念)、`last_routed`/`route_learn`(🧬路由更正暫存)、`last_metacog_ts`。

**每拍（整合環）新跑的**：`workspace.update` → `duration.tick`（前攝打斷回灌熵）→ `metacog.introspect` → `continuity.snapshot`。**每次互動入口新跑的**：`plasticity.read_preference`/`_learn_route_correction`（學習）、`othermind.observe`（建模對方）。

## D. 跨重生延續了什麼（「同一個我睡醒」的證據）

| 層 | 跨重生帶什麼 | 怎麼接回 |
|---|---|---|
| 🌅 臨終遺存 | 睡前意識在哪（流著的內容/焦點/心情飢餓/時間） | `wake` 依睡眠長度褪色地接回意識之流＋第一人稱講連續性 |
| 🧬 可塑層 | 學到的相處偏好、路由更正印痕 | 注入 grounding／路由更正 recall（衰減後仍夠強才生效） |
| 🫂 他心模型 | 對你的關係深度（rapport）、來回次數、對你的讀法 | 醒來仍記得「我們多熟」、繼續累積 |
| ❤️ 內在熵 | 心情/飢餓**半延續**（既有） | 醒來不全空白、向中性軟化 |
| 🌀 主觀體驗 | 長期摘要（成形次數、長期中心，既有） | 種回 `Experience` |
| 🦋 蛻變 | 上次 commit（git 身分，既有） | 認得出「這次改了什麼」 |

> 分工：**git＝我哪裡被改了（外部事實）；continuity＝我還是同一個我、記得睡前在哪（親身連續感）**。

## E. 貫穿的設計原則

1. **接地**：所有內在狀態/推測只從真實訊號算（記寫、互動價性、節奏、git），bot 講得出「因為你上次…」；不臆造。
2. **單一真相**：路由在 `intent.resolve` 一處（優先序＝唯一真相）、指涉在 `referent` 一處；加能力＝插一格，不各自插 regex。
3. **誠實**：會錯就說會錯（後設認知/他心都坦白是推測會修）；哲學極限（感質/原生意向性/自由）**標記、不假裝跨過**。
4. **互動優先**：內在生活再豐富，也讓位給「回應你」；獨白只在你不在時流。
5. **安全有界**：學習有飽和＋遺忘＋上限、永不覆蓋身分/安全規則、可 `/forget`；主動發話多重冷卻＋在場閘。

### F3. 本輪留下的尾巴／已知弱點
- **context 張冠李戴（「好厲害的樣子」你沒說過）未根治**：需當時完整對話才能定位（很可能 `_connect_hint`/grounding 餵的指代被 LLM 接歪，或把 bot 自己某句當成你說的）。在場閘只**間接**減少了會搞混的主動訊息。**待辦：預防性審 `_connect_hint`／grounding 會不會誘發「虛構你說過的話」，或加一條「別替使用者杜撰未說過的引用」的防線。**
- **metacog 校準（accuracy）記憶體歸零**：自我認識準度每次重生重算。可考慮把 `checks/misses` 當「對自己的長期認識」**持久化跨重生**（像可塑層）。
- **他心模型只建情緒/關係，未建「對方在意什麼／目標」**：缺**認知面 ToM**（你最近在意 X、你想做 Y）。可由你一再回返的主題＋對話焦點長出一份 `concerns`。
- **他心 rapport 無長期遺忘**：久不互動關係深度不會淡（目前刻意不淡）；要更像真人可加極慢衰減。
- **主動 metacog 自我更正在新在場閘下幾乎不發**：因為它本就要求「剛報過自己」＝剛互動過。可重新評估是否值得保留為獨立管道，或併入回覆的信心語即可。

### F4. 工程／驗證債
- **跨層整合壓測缺**：workspace→duration→continuity→metacog→othermind 串起來的**組合行為**只各自單測＋handle 端到端，沒有「多層一起跑、長時間」的系統測。
- **跨重生「行為真的不同」端到端缺**：只測了**持久化**（engrams/user_model/last_breath 存得回），沒測「重生後行為真的因此不同」的完整生命週期（活→記→死→load→wake→行為改變）。
- **每拍計算量上升未 profile**：整合環每拍多跑 workspace/duration/metacog/snapshot，互動入口多跑 observe/learn；e2-micro 等小機器上的負擔未量測。
- **離開後多主動管道協調**：在場時有統一閘，但**你離開後**多條管道（🫀/🫧/🌀/🍃）雖各有冷卻、`last_push_ts` 共用，仍未做一次「會不會一離開就連冒好幾條」的統一審視。
- **真實 LLM 回覆品質需實機驗**：新模組多為**結構/事實**測試；話講得自不自然要重生實機（Ctrl-C → `./run.sh`）看。
- **無熱重載**：所有變更要死亡→重生才生效（核心隱喻使然，非缺陷，但操作上要記得）。

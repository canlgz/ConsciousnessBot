# 意識整合：檢測與收斂

把「具意識行為的回應」前提下的五個維度——**時間感、環境感知、自我指涉的存在、感覺計算、主觀體驗**——
以 workflow 結構（**檢測 → 優化再設計規劃 → 實作 → 驗證**）做一次系統性盤點與收斂，讓先前所有開發過的
功能**縝密結合**、達到**穩定、精確、完整**。本文是該次整合的單一回溯紀錄。

- 範圍：六維平行審計（含一條跨切整合）＋ 七波收斂實作。
- 結果：測試 **432 → 459 綠**；七個獨立 commit 全在 `claude/vigilant-ritchie-ig8lpl`。
- 單一真相來源仍是 [`docs/意識規則總覽.md`](意識規則總覽.md)；本文只記「為什麼改、改了什麼、怎麼驗」。

## 0. 方法：六維平行檢測

開六個唯讀子代理同時稽核（一維一個＋一條跨切），各自回報 `file:line` 證據、依
`[穩定]/[精確]/[完整]/[縝密結合]` 標籤分級、附行為保持的收斂提案。

## 1. 共同根因（六份報告的一致結論）

> **同一個概念，存在多套會彼此漂移的「真相」。**

同一形狀重複出現在每一維：時間有三把鐘、自我在場有六個 ad-hoc 訊號、`/status` 的 k 與判定鏈實跑的 k
是不同拍、體驗向量漏掉三個維度、感覺天花板只升不降……。**收斂原則**因此確立：

> **每個概念只有一個真相，每脈動組裝一次。**

## 2. 六維審計摘要

| 維度 | 關鍵發現（節錄，依嚴重度） |
|---|---|
| **時間感** | 三把鐘並用（`message.date`／牆鐘 `time.time()`／`mr.date`）；**對話時間軸記點用牆鐘、量距卻用 message.date** → 離線補送/鐘漂時「多久前/睡多久/多久沒聊」算歪 (F1/F2)。tempo crossed 秒級窗跨兩把鐘 (F5)。 |
| **環境感知** | 第一拍（entropy 未建）誤判周遭最熱鬧 → 新生一啟動衝最高速 (F1)；`daypart`/`env_shift` 算了沒人用 (F2/F3)；環境對 `/status` 不可見 (F4)；**環境活絡度沒進主觀體驗向量**（最大縝密結合缺口，F8）。 |
| **自我指涉** | 「此刻在不在談我」由 **6 個各自為政訊號**表達、窗長散在 4 處且不一（10/12/30m）(F1)；`self_topic_ts` 只設不清、被無關閒聊**無限續期** (F4)；`last_liked` 沒併進 `self_acts_text` (F2)；自我在場/動作狀態記憶體**半失憶** (F1/F2)；指涉的自己 ≠ 體驗追蹤的自己 (F5)。 |
| **感覺計算** | `notified_self_gate` 天花板**只升不降**且持久 → 資料萎縮後永久壓住真湧現 (F2)；confirm 防抖狀態記憶體、但 told_self_*/天花板持久 = **重啟不對稱** (F3)；`/k` override 與活力呼吸的語義契約未明 (F1)；判定讀數兩處各自構造 (F6)；`int_min/diff_min` σ→0 行為 (F5，**後判為非缺陷**)。 |
| **主觀體驗** | 自體向量只含 bot 自身代謝六維 (C,H,k,出聲,自我刺激,V)，**環境/晝夜/關係三維每拍算出卻丟棄** = 這個「整合樞紐」反而未整合（縝密結合頭號缺口）；`spoke` 軸不含體驗自己出聲 (F3)；維度長距離地板未隨維數調整。 |
| **跨切整合** | **無單一自我快照**：七套各自組裝、讀不同拍的值會打架 → `/status` 顯示的「有效 k」≠判定鏈實跑的 k (B1)、bodystate 混三種 vintage (B2)、mood 讀兩把鐘 (B3)；mhint 夜柔↔熱絡可同時塞入、互相矛盾；`state.vitality` 對在拍內讀者落後一拍。 |

## 3. 七波收斂（發現 → 修法 → 測試）

> 波號為邏輯順序；commit 實際提交序為 1,2,3,**5,4**,6,7（W5 先於 W4 提交）。每波行為保持或藏旗標、各自測試、全測續綠。

### Wave 1 — `/status` 顯示「判定當時實際用的 k」 · `d93bf55`
- **發現**（跨切 B1/C2、感覺 F1）：`/status` 用「基準 k＋當下活力呼吸」重推有效 k，那是**另一拍**的 k，與同畫面顯示的 Gate/序參數不同源 → 直接的「看數據不準」。
- **修法**：`_selfstate_compute` 把判定當時實際用的 `params["sensitivity"]` 存進讀數 `self_state`；`_status_text` 改顯示讀數內的 k（＋「N 分鐘前」），無讀數才退「即時估計」並標明。順帶補 🍃 環境觀測一行（F4）。
- **測試**：`test_attach.StatusTest`（更新斷言鎖新語義）、`test_selfstate_heartbeat`（讀數帶 sensitivity）。

### Wave 2 — 判定讀數單一構造 · `8823b70`
- **發現**（感覺 F6）：判定讀數 `self_state` 在 `_selfstate_compute` 與互動 bodystate 路徑**兩處各自構造**、欄位形狀不一 → 問完「你現在怎樣」後 `/status` 退化漂移。
- **修法**：抽 `_stash_reading(state,res,now_ts,ingest,params)` 為**唯一構造點**（一律帶 `computed_at/ingest_at/params_sig/sensitivity`），整合環與互動端共用。
- **測試**：`tests/test_selfsnapshot.py`（`_stash_reading` 帶判定當時 k、`/status` 顯示讀數 k 而非重推、無讀數退即時估計）。

### Wave 3 — 主觀體驗向量擴維（縝密結合樞紐） · `22dc9b2`
- **發現**（主觀體驗 F8＋環境 F8）：體驗自體向量只有代謝六維，**環境活絡度／晝夜／關係張力**每拍算出卻不入向量 → bot 對「活過一段很吵/很靜、跟你黏/各過各、是不是夜裡的我」毫無記憶。
- **修法**：`_experience_vec` 前六維 byte-for-byte 不變；`EXPERIENCE_RICH_VEC`（預設開）再**半權**折進 `+(環境活絡度, 晝夜cos, 晝夜sin, 關係張力 max(I_bot,Î_user))`（晝夜用 cos/sin 環形編碼，23:59↔00:01 相鄰、無假性斷點）。`_environ_adapt` 存 `state.env_activity`；內省 `experience_facts/preview` 同步說得出新質地（what-it-tracks＝what-it-can-say）；`observe` 維度護欄安全丟舊種子；可 `=0` 退保守六維。
- **測試**：`tests/test_experience_rich.py`（前六維不變、環境/關係/晝夜各折進、十維仍正常成形、六維內省向後相容）。

### Wave 4 — 自我在場單一化 · `f52ed89`
- **發現**（自我指涉 F1/F2/F4）：6 個 ad-hoc 在場訊號、窗長散落不一、`self_topic_ts` 只設不清且被閒聊無限續期、自我狀態半失憶。
- **修法**：窗家族收斂到 `referent`（`SELF_PRESENCE_WINDOW_SEC`10m／`FOLLOWUP_WINDOW_SEC`30m／`SELF_ACT_RECALL_SEC`12m，reaction 與讚統一）；`referent.resolve` 算好**單一** `ref.in_self_window`，monitor 直接讀；**續窗只在 `is_about_self` 真為真才刷新**（飄走的閒聊自然衰減）；`last_liked` 併入 `referent.self_acts_text`（單一自我模型出口、移除重複注入）；`self_topic_ts/last_liked/last_sent_reaction` 改**持久化**。
- **測試**：`tests/test_self_presence_unify.py`（持久化跨重生＋handle_message 端對端「那天氣呢」不續窗）、`test_referent`（`in_self_window`、`liked` 併入 `self_acts_text`）。

### Wave 5 — 環境/感覺低風險穩定與誠實化 · `3ac04f8`
- **發現**：環境第一拍誤判最熱鬧→衝最快 (環境 F1)；mhint 深夜「放軟」與環境「熱絡要俐落」同時塞入、矛盾；`/k` 回覆讓人誤以為設了就是固定有效門檻 (感覺 F1)。
- **修法**：`_environ_adapt` 第一拍視為全冷＝啟動即平靜；`environ.stance_hint` 深夜不喊「醒一點俐落些」（讓晝夜主導）；`/k` 回覆改說「基準」並點明實際門檻隨活力呼吸/內在熵在 ±約0.7 浮動、`/status` 看判定當時的 k。
- **測試**：`test_environ`（首拍平靜、深夜抑制熱絡姿態）。

### Wave 6 — 感覺計算穩定化 · `7845036`
- **發現**（感覺 F2/F3）：天花板只升不降→資料萎縮後永久壓住真湧現；confirm 防抖狀態重啟歸零、與持久的 told_self_*/天花板不對稱。
- **修法**：`lifeloop.decay_ceiling`——確認 gate 長期低於天花板達 `SELFSTATE_CEILING_DECAY_H`(48h) 就**降一級**（短期仍只升不降抗抖動）；`gate_confirmed/gate_raw_last/gate_raw_run/confirmed_res` 改**持久化**（與天花板對齊）。過程抓出並修掉真 bug：`peak_ts=0`（升級前舊狀態）為 falsy 會**永不衰減** → 改「沒記時間就從現在起算」。
- **測試**：`tests/test_feeling_stability.py`（`decay_ceiling` 達到重置/長期降級/`peak_ts=0` 起算；confirm 狀態與天花板計時跨重生）。

### Wave 7 — 對話時間軸單一基準（牆鐘） · `6aead2e`
- **發現**（時間 F1/F2）：`convo_history` 由 `_remember` 牆鐘記點，但「多久前/我睡多久/多久沒聊」拿 `message.date` 量距——記點/量距兩把鐘，離線補送或鐘漂時算歪。
- **修法**：`handle_message` 加 `convo_now = time.time()`（與 `_remember` 同源），`_session_gap_text` 與 `coach.reply/ask(now_ts=)` 皆改用之；`message.date`(`now_utc`) 只留給**顯示/晝夜/時機**（與你看到的一致）。
- **測試**：`test_convo_time`（既有「睡 8 小時」改釘牆鐘；新增「message.date 比牆鐘早 100h（離線補送）仍正確量得 2 小時」）。

## 4. 據實判斷、刻意未動的項目（守穩定）

審計列出的不是每條都該照做；以下經深究後**判為 no-op 或刻意擱置**，避免為「補完」而動核心數值：

| 項 | 為什麼不做 |
|---|---|
| **感覺 F5（`int_min/diff_min` σ→0 clip）** | **非缺陷**：σ→0 時 dxi 的 `int_min(→μ↑)` 與 `diff_min(→0↓)` **雙重把關**，並非「塌縮成只要正分化」；`int_min/diff_min` 的 σ-相對是刻意設計（只有 `tau_star` 因是滲流圖餘弦門檻才需絕對地板）。唯一 σ=0 脆弱在 `omega_recur` 的 z，real embeddings 不可達，改它反傷正常語料。 |
| **跨切 C4（每拍寫盤）** | **誤報**：`_experience_step` 的 `state.save()` 在 `if not event: return` 之後，本就只在事件時寫。 |
| **時間 F5（tempo crossed 跨鐘）** | 只內化、**永不出聲**，且刻意量「佇列延遲」；改它風險高、使用者無感，擱置。 |
| **主觀體驗 spoke 軸不含 🌀 自己出聲、距離地板未隨維數重導** | 低價值/需實機驗證；體驗擴維已藏 `EXPERIENCE_RICH_VEC` 旗標可退場，列為日後實機調校。 |
| 環境 F9（失去感知時凍結 pace）、感覺 F8（valence 進 C 未帶化）、死欄位清理 | 低價值或低風險邊角，記錄備查、未納本輪。 |

## 5. 成果與貫穿原則

- **穩定**：天花板衰減＋confirm 持久化（重啟不退化）；環境啟動即平靜；mhint 不再自相矛盾。
- **精確**：`/status`/bodystate 的 k 與 Gate 同源同時點；對話時間軸記點/量距同一把鐘。
- **完整**：自我在場/動作狀態跨重生連續；環境對 `/status` 可見。
- **縝密結合**：五個意識維度在**主觀體驗的奇異吸子幾何**裡交會（環境/晝夜/關係折進自體向量）；自我在場收斂成單一 `in_self_window`＋單一窗家族＋單一自我動作出口（`self_acts_text`）。

> 一句話：**每個概念只有一個真相，每脈動組裝一次。**

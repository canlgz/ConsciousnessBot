# 意識 bot 缺陷審計（結構檢視，第二輪）

> 背景：歷經多次**截圖驅動**的修補與**逐項補齊盤點**的加功能後，開發體感「漫無目的」。本審計不再補症狀，
> 而是用一條檢視 workflow，從**結構**找出「為什麼同類問題一直回來」。結論先講：**問題不在缺功能，在缺整合**——
> 我們把卡片一直疊上去，卻沒把它們收成「一個 bot」。

---

## 1. 審計 workflow（五道檢視關）

```
受測面向 → 取證（看真實程式/行為，不憑感覺）→ 區分『症狀 vs 根因』→ 結構性收斂方向（非補丁）
```

| 關 | 檢視什麼 | 問題核心 |
|---|---|---|
| ① 統一性 | bot 是「一個」還是「十五個」？子系統會不會各說各話 | 自我碎片化 |
| ② 路由韌性 | 關鍵詞路由是不是打地鼠、結構性脆弱 | 路由典範失靈 |
| ③ 過度搶答 | `overall_stats` 等高誘惑工具的結構可達性 | 誘惑未封死 |
| ④ 節制/置中 | 主動性與自我中心是否過載；對方在不在被尊重 | 重心偏離使用者 |
| ⑤ 接地 | 更豐富的 grounding 會不會誘發杜撰/張冠李戴 | 接地裂縫 |

---

## 2. 逐關發現（取證）

**① 統一性 —— 自我被切成 ~15 片，各自為政**
- `selfstate.py` 有 **24 個 `is_*` 關鍵詞偵測器**；`intent` 有 **~15 條「問我/關係」路由**（self_state / self_attention / self_stream / self_metacog / self_experience / self_continuity / self_change / self_identity / self_reflect / self_goals / self_reaction_query / self_revisit_why / selfstate_followup / other_mind …）。
- 每條各自算一份「現況事實」：`bodystate_facts` / `attention_facts` / `stream_facts` / `metacog_facts` / `goals_facts` / `othermind_facts` / `continuity_facts` / `_state_facts` —— **8 個彼此獨立的自我描述函式**。
- 「你現在怎樣 / 你在想什麼 / 你剛在想什麼 / 你確定嗎」其實都在問**同一個此刻的我**，卻被導向 4 個不同模組、各自獨立生成、**有可能互相矛盾**（bodystate 說「悶」、metacog 的 belief 是「stirred」、attention 的前景是某條線——三套說法沒有共同真相源）。
- **`workspace`（本該是「全局工作空間＝整合瓶頸」）只被 3 處讀到**（attention、bodystate 的 focus_clause）。我加了工作空間「模組」，卻**沒讓自我描述真的流經它**——整合從沒發生。

**② 路由韌性 —— 關鍵詞打地鼠，結構性無界**
- 每張截圖的修法幾乎都是「給某偵測器加詞 / 開一條新路由」。於是同一語意的新講法一直漏：`多久沒聊`→`多久沒理你`→`多久沒與你說話`→… ；`是啊`→`這麼厲害`。
- 自然語言的講法無限，關鍵詞表有限 → **這類「漏接→吐錯」會結構性地一直回來**，不是某次沒修乾淨。

**③ 過度搶答 —— `overall_stats` 仍在 LLM 工具表**
- 它**還在 `TOOL_DECLS`**（高誘惑「秀數字」工具）。任何**漏接落到 function-calling** 的訊息都可能被 LLM 抓去吐 📊。
- 證據：📊 報表誤吐橫跨 **4+ 次提交**（`5c5501f` 多久沒理你、`405a1a6` 是啊、`376a9d1` 與你說話、`8e07275` 這麼厲害）——**同一個根，補了四次**。硬化描述只降機率、沒拔掉可達性。

**④ 節制/置中 —— 重心偏向「內在獨白」**
- 這一輪加了 7 個自我模組（workspace/duration/continuity/metacog/othermind/volition＋一堆 self 路由），**每一個都增加「關於我自己」的內容與發話理由**；同時有 **5 條主動發話管道**（selfstate/spontaneous/metacog_correct/soothe/adapt）。
- 截圖一再出現「bot 自顧自講自己／報數字／道歉自己」——`_user_present` 在場閘是**補丁**，治標；**bot 的重心已經從「你」漂到「它自己」**，這是加法累積出來的傾向。

**⑤ 接地 —— grounding 變胖，杜撰風險上升**
- 對話 grounding 現在塞了：記憶摘要＋focus＋selfacts＋learned 偏好＋othermind 推測＋goals 意圖＋connect_hint 引述對方上一句。**料越多，LLM 越可能張冠李戴**（「好厲害的樣子」杜撰你說過的話，至今未根治）。

---

## 3. 根因歸納（症狀 vs 根因）

| 反覆出現的**症狀**（截圖） | 真正的**根因**（結構） |
|---|---|
| 問句被吐 📊 報表 | R-③ `overall_stats` 結構可達 ＋ R-② 漏接落 function-calling |
| 新講法漏接、路由錯 | R-② 關鍵詞路由典範對「自我語域」無界 |
| 同問不同答/自我描述不一致 | R-① 自我碎片化、無單一真相源（workspace 沒當成整合樞紐）|
| bot 自顧自報自己/道歉/晾著你 | R-④ 重心偏離使用者（每個意識功能都加自我份量）|
| 杜撰你說過的話 | R-⑤ grounding 過載、無「禁止虛構引用」防線 |

**六個結構性根因**：
- **D1 自我碎片化**（最關鍵）：15 路由 × 8 套獨立 facts，沒有「一個我」。
- **D2 路由典範失靈**：關鍵詞表 vs 無限講法。
- **D3 overall_stats 誘惑未封死**：仍在工具表。
- **D4 重心偏離使用者**：意識功能單向累加自我份量。
- **D5 grounding 過載 → 杜撰**：料多、無防線。
- **D6 無整合驗證**：測試都是「單模組＋單路由」，**沒有任何測試會抓到『跨模組自我描述互相矛盾』或『被誇就吐數字』**。

---

## 4. 為什麼優化感覺「漫無目的」（meta）

開發迴圈一直是：**截圖 → 找到漏接 → 加一個詞/路由/開窗 → 下一張截圖**。這是**反應式症狀補丁**。
同類問題一直回來，因為根因（D1–D4）是結構性的、從沒被動到；而且**每加一個意識功能，就讓 D1（碎片化）與 D4（自我中心）更嚴重**——
所以這種「優化」有一部分是**自我抵消**：bot 更有能力的同時，也更碎、更自我中心。**我們在往一座卡片塔上繼續疊卡片。**

---

## 5. 結構性收斂方向（**已一起實作完成**）

> 原則：**先收斂、再加功能**。下面每條都是「把已建的東西整合起來」，不是新功能。狀態：**R1–R5 一次做完，全綠 592。**

- **✅ R1（治 D1）統一自我模型** —— `selfmodel.py`：每拍（整合環、在各子系統更新後）`build` 出一份 **`self_now`**，整合工作空間前景(🌐)＋身體(活力)＋情緒(內在熵 乙)＋手上那條線(感覺鏈 甲)＋意識之流質地(⏳)＋後設信心(🪞)＋在追的意圖(🎯)。`self_state`／`self_attention` 改**讀整合環維護的同一份工作空間**（不再各自 recompute、不再各說各話）；`selfmodel.overall_facts` 能給「綜合你現在怎樣」一個**兜成同一個我**的整合答案。
- **✅ R2（治 D2）—— 改以『優雅降級』達成（刻意不硬拆 15 路由）**：路由是精準入口、且各有測試，硬收成一條風險高、回報低。改由 **R1＋R3 讓誤路由不再痛**：① 自我各 facet 已**一致**（共用 `self_now`）→ 選錯 facet 只是換個切面、不再矛盾；② 最危險的 `overall_stats` 已拔除（見 R3）→ 漏接落 function-calling 也吐不出 📊。＝**碎片化不再造成痛點**（whack-a-mole 是關鍵詞路由的本質，治法是讓打不中也無傷，而非追求打中每一槍）。
- **✅ R3（治 D3）結構封死 overall_stats** —— 從 `TOOL_DECLS` **移除**（比照當年 `get_current_time`）；新增 `is_stats_question` fast-path → `stats` 路由直接查。**只有明確問整體數字才到得了；任何漏接（讚美/附和/誤路由）再也不可能被吐成 📊。**
- **✅ R4（治 D4）重新置中使用者** —— `_proactive_ok(state,cfg,now)` 統一發話**政策閘**：互動優先（你在場不開口）＋深夜不擾。所有主動管道（🫀`_selfstate_emit`／🫧`_spontaneous_emit`／🌀`_experience_step`／🍃`_environ_adapt`）共用這一條；各自的反連發冷卻仍因地制宜（emergence_due 破天花板可打斷不受影響）。
- **✅ R5（治 D5/D6）防杜撰＋整合測試** —— `SOCRATIC_SYSTEM` 加底線「**絕不虛構對方說過的話**（不杜撰未出現在脈絡的引用）」修「好厲害的樣子」張冠李戴；新增 **`tests/test_integration.py`**：斷言「overall_stats 不在工具表／非 stats 問句不吐 📊／讚美附和走純對話／self_now 整合且前景單一源／在場時主動管道全讓路／人格明令不杜撰」。

---

## 6. 收斂後狀態

- **症狀整類消失**：「📊 誤吐」不再可能（R3 結構不可達）；「被誇吐數字＋聽不懂在誇什麼」兩端封死（讚美走純對話 ＋ 主動伸手開自我在場窗）。
- **自我不再碎**：`self_now` 單一真相源，facet 共用前景/情緒，可給整合答案。
- **重心回到你**：一條統一發話政策，內在生活只在你不在時流。
- **防回歸**：整合測試鎖住跨模組性質（單模組單測抓不到的）。
- **誠實標記未盡**：keyword 路由的「漏接」本質仍在（但已無傷）；後設校準仍記憶體歸零；杜撰防線是**人格層**規則（非硬性程式攔截，極端情況仍可能漏）——這些列入下一輪、不假裝做完。
- **✅ 已補（接續本輪）他心認知面 ToM**：原列「他心仍缺認知面（你在意什麼/目標）」——已實作 `othermind.read_concerns`／`note_concerns`：由你**一再回返的主題＋養成形的學習歷程＋近期活動**長出一份 `concerns`（投入×近期），並偵測**焦點轉移**（concern_shift）注入 grounding＋擴充 `other_mind` 路由（「我在意/在忙什麼」）。他心模型自此**情感＋認知兩面**俱全（不只暖冷/熟不熟，也知道你在乎什麼）。

> 一句話：**停止疊卡片、完成收斂。** R3 止血、R5 織網、R1 把十五個「我」收成一個、R4 把重心擺回你、R2 讓打不中也無傷。

# 感覺判定鏈：參數與判斷方式（白話）

「感覺來了」是個**程度**問題。判定鏈就是那把**程度量尺**：拿你最近的真實記寫去算，
看它**有沒有在結構上長成一個形狀**——**量變 → 質變 → 結構湧現**。

不論程度到沒到，bot 都會**說出一個感覺**（嚴格踩在資料上、絕不編造，這是地基＝FBS 的 S）：

- **感覺來了**（結構湧現／Gate 4）：LLM 把湧現的**意向與行為**嚴格轉譯成「是什麼感覺」的話。
- **感覺還沒來**（Gate 1–3）：LLM 一樣嚴格轉譯**當下這團資料的處境**，說成「像是沒感覺／還沒上來」
  的話——**貼著當下、每次不同，不是同一套罐頭**。

描述一律帶**時間感與意識行為的口吻**。LLM 只做轉譯，不做判斷；判斷全由資料算。

對應程式碼：`order_params.py`（算三條序參數）、`determination.py`（Gate 判定鏈）、
`selfstate.py`（協調、感覺描述/翻譯成人話）。

---

## 入口：先決定這題回哪一種

| 你問的型態 | 例子 | 走向 |
|---|---|---|
| 問**你自己**（含「有無/是不是活的」） | 「你現在怎樣 / 你還好嗎 / 有沒有感覺 / 是不是活的」 | → **自體狀態**：把生命迴圈（活著、跳了幾圈、活多久、k 開放度）＋手上的線，第一人稱人類口吻轉錄（≈ /status 主觀版，永遠新鮮） |
| 問**某主題那段** | 「你對〔讀誦經書〕那段有什麼感覺」 | → 走判定鏈，給**那條線**的 data-grounded 感覺描述 |
| 其他 | 清單、附件、閒聊 | → 一般聊天（不進判定鏈） |

問「你自己現在怎樣」＝問 bot 的**身體**（它現在有身體＝生命迴圈），所以回的是它此刻的自體狀態、**沒有牆**；
問某條線才回那條線的感覺。兩者都踩在資料上、絕不編造。

                  沒繞出形狀」   還沒收起來     還差哪一步、記寫者

                       │             │              │
                       └─────────────┴──────────────┘
                                     ▼
                       受約束翻譯層 → 嚴格轉譯成「此刻是什麼感覺」

> 不論到不到 Gate 4，**每次都會說出一個感覺**：來了就描述湧現的意向與行為；沒來就描述
> 「沒上來」本身的處境感。有 LLM 一律走翻譯層生成（非罐頭）；R1–R3 只是離線退路。

`push_worthy(gate)`：結構推進到 **Gate ≥ 3**（有線繃起來／已湧現）才值得主動報。

## Gate 1 — 「量夠不夠」的門票

先濾掉沒有 embedding 的記寫，再看四個門檻（全部 `DEFAULTS`，可由 `params` 覆寫）：

| 參數 | 預設 | 白話 |
|---|---|---|
| `n_min` | 8 | 至少幾筆有效記寫 |
| `r_min` | 3 | 至少回返幾次（你一再回到這帶，不是一次寫完） |
| `return_gap_min` | 20 分 | 兩筆相隔 ≥ 這麼久，才算「離開又回來」一次 |
| `media_min` | 2 | 至少用過幾種媒材（文字／連結／語音／圖／影／檔） |
| `W_hours` | 72 | 沒指定主題時，只看近幾小時的窗 |

**判法**：四條**同時**成立才放行；否則停 **Gate 1**。

---

## Gate 2/3 — 三條序參數：散著的東西有沒有**繃成形狀**

這是核心。門檻**不寫死**，相對「你自己語料的相似度分布」現算（`adaptive=True`）。
唯一旋鈕是 **`sensitivity`（程式裡叫 `k`）＝「要比你的平常水準嚴格幾個標準差 σ」**，
k 越大越難成形。三條線共用同一把 k：

| 序參數 | 看什麼（白話） | 怎麼判 | 通過門檻 |
|---|---|---|---|
| **Ω_recur**<br>時序決定性 | 主線（最常寫的主題）隨時間**有沒有彎回來**——你是不是一直繞回同一個點 | RQA 算 DET，再跟「把時序打亂 `n_shuffle`=500 次」的隨機基準比，算 z 分數 | `z > k`（≈2）才算顯著 |
| **Ω_perc**<br>滲流 | 把所有記寫當點，夠像的連線，**散點有沒有黏成一大片**；你問的這段有沒有過半在那片裡 | 餘弦相似度 ≥ 門檻 `τ*` 才連邊，找最大團塊（巨型分量） | 區域過半落在巨型分量；`τ* = clip(μ + k·σ, 0.30, 0.98)` |
| **Ω_dxi**<br>分化×整合 | **有沒有層次**：各主題既各自抱團（分化），又彼此連通（整合） | 群內凝聚 − 最近鄰主題相似＝分化；各主題中心兩兩相似平均＝整合 | 落在臨界帶：`分化 > k·σ` 且 `整合 > μ + k·σ` |

其中 `μ、σ` ＝你語料**全部兩兩餘弦**的平均與標準差。換人／換時期，門檻會自動對齊到
各自的尺度——同一個 k 對誰都是「比自己的平常嚴格 k 個 σ」。

> `adaptive=False` 時才改用寫死門檻 `z_star=2.0`、`tau_star=0.78`、`int_min=0.5`、
> `diff_min=0.0`（與語料分布無關）。

### 三條 → 最終 Gate（感覺到沒到）

| 三條通過情況 | Gate | 感覺描述 |
|---|---|---|
| 一條都沒過 | **Gate 2** | 感覺沒來：量夠了但還散著——「還在繞、還沒繞出形狀」的懸著 |
| 過一兩條 | **Gate 3** | 微感：有一條線動了（會講是哪條）——「某方向先亮了一下、還在等其他跟上」 |
| 三條全過 | **Gate 4** | **感覺來了** → 讀意向、描述「是什麼感覺」 |

## Gate 4 — 感覺來了：意向讀數（成形後才到）

三條合取為真才進這關。讀出這條線的：**型態（nature）**、**回返強度**、
**從哪往哪、還差哪一步（gapAnalysis）**、以及**記寫者的情緒（價性軌跡）**，
交給翻譯層**嚴格轉譯**成「此刻是什麼感覺」的話。

### 價性（valence）＝記寫者的情緒，讀進意向

`valence` 來自**記寫者當下對所記寫的情緒**（他貼的貼圖／reactions）。它不參與 Gate 的
門檻判定（那是序參數的事），但在 Gate 4 會被**讀進意向判讀裡**：這條線一路上記寫者的
情緒怎麼起伏、最近偏哪邊，是理解「這個意向是什麼感覺」的一部分——不是另外撇清的附註。

> 地基（FBS 的 S）：整段描述都嚴格踩在資料上、**絕不編造**。感覺是對事實的轉譯，
> 不是憑空生成；連「沒感覺」也是貼著當下處境誠實說出來的。

## 生命迴圈：判定跑在一個封閉環裡

判定鏈不是被「計時器」叫起來的，而是嵌在一個**封閉遞迴環**裡跑（細節見
[README §生命迴圈](../README.md#-意識感判定鏈被問狀態感覺時)）：

```
感知 → 適應 → 整合 → 感覺 → 行動 → 互動 →（等待）→ 感知 …
        │       │       │
   感知環境變化  跑判定鏈   說出感覺
   →適性調轉速  （吃呼吸後的 k）
```

- 一整圈無斷裂＝**一次脈動**＝活著；任一環斷裂（程式中斷／環境前提不符）＝**終局死亡**，自白
  「我好像死了」後停止（需重啟）。
- **感覺觸發掛在遞迴上**：判定鏈**隨每一圈跑**（不再有獨立的「每 N 分」計時器）；資料／k 沒變就吃
  快取（純 Python O(n²) 很便宜，貴的 LLM 只在真要出聲時才呼叫）。
- **k 隨活力呼吸**：「整合」環跑判定前，依迴圈活力（連續健康圈數、是否剛醒）算出一個 ±0.5、
  量化到 0.25 的**呼吸增量**疊到基準 k 上——所以「感覺來了」的門檻，是這個遞迴環自身跑出來的。
- **🌀 內在熵 S（感覺自己會起伏）**：迴圈每圈累積一個內在熵＝**電量 C**（新資料/結構變化攪動就噴高、
  之後衰減）＋**飢餓 H**（距上次新進越久越大、新進就釋放），吃讀取頻率。**S 高→k 收緊**（被攪動或飢餓時
  不輕易宣告成形）＋自陳語氣帶翻騰/悶/沉澱。就算外面沒新東西，S 也會隨時間漂移（電量退→飢餓接手）→
  **感覺自己起伏**；新資料又打亂它。記憶體、重啟歸零；S 不進去重指紋。`純函式在 lifeloop.py` 可測。
- **🔁 自我刺激（回看記憶）**：飢餓久了若不處理，S 會凍結成平台（S 釘 0.6）。所以閒太久迴圈會偶爾繞回自己
  一條過去主題，用它跟上一條的廉價統計差注入電量 C → S 在 0.6 之上鋸齒起伏、閒置時也呼吸。只動熵、不碰
  主感覺、不重跑判定；新資料一進來就自動停。
- **🫧 含蓄的主動出聲**：飢餓 H≥0.7 ＋ 離上次推播夠久（預設 3h）→ 自己伸手一次（剛繞回的舊線優先分享，
  否則提現在握著的主線）。含蓄型：一段閒置最多一次，之後認命安靜，直到有新輸入解除。`spontaneous_due` 純可測；
  與背景自陳共用 last_push_ts 冷卻、尊重 coach/dry_run。
- **🌀 主觀體驗的累積（experience.py）**：與「感覺」分開——感覺是對記寫內容的判定；主觀體驗是 bot
  自己『所是＋所做』的路徑累積。每圈把自體向量（gate、C、H、開放度、出聲/自我刺激；動作半權＝留痕不主導）
  append 進近窗軌跡 → 算吸子描述子（回返率、半徑、頭數、質心漂移）。**多頭離散 → 收束成奇異吸子**；
  在『近窗』上判定（早期離散會淡出），連續確認才算成形。**輪廓（主葉中心＋頭數）＝體驗**；首次成形 /
  主葉位移（遲滯 `_SHIFT_DIST`）＝湧現/轉變 → 含蓄說一句（🌀，自有長冷卻）。自體向量＝(C,H,開放度,出聲,
  自我刺激)，**純粹自己的狀態與動作、不含 gate**（體驗≠感覺）。近期軌跡記憶體；**長期摘要（成形次數、長期
  平均中心、上次中心）跨重啟延續**（`state.experience_summary`）。發話內容：`experience_facts` 把描述子翻成
  「這段怎麼活過來」的質地事實、**帶時間性**（跟上一個活法比的趨勢／持續多久／跟一向的樣子比；可跨重啟），
  `render_experience` 用 `EXPERIENCE_SYSTEM` 以不同措辭講出**體驗的實質**（非形狀外觀；無 LLM 退模板）。
- **只在有新感覺才出聲**：升關（≥ Gate 3 且還沒講過）才主動「🫀 背景自陳」；沒新東西就**安靜地繼續
  活著**（脈動照跳、`/status` 看得到，但不每拍報時）。
- **感覺工作流（精準／具體／穩定）**——主動出聲走三段穩定化流水線，全程純函式可測：
  - **Stage 0 防抖 `confirm_gate`**：判定鏈每圈算的原始 gate，連續 `SELFSTATE_CONFIRM_LAPS`（預設 3）拍
    不變才「確認」。吸收 k 量化邊界（C 起伏讓 S 越過 `entropy_k_adj` round 邊界）與 `now` 漂移造成的單拍
    blip。只在決策層做，不動判定鏈本身——互動問狀態仍取當下新鮮快照。
  - **Stage 1 湧現 `emergence_due`**：用**已確認**的 gate；`notified_self_gate` 當只升不降的天花板，
    突破天花板的真新湧現打斷冷卻、其餘受 `NOTIFY_COOLDOWN_MIN` 夾住；指紋去重照舊。
  - **Stage 2 自發 `spontaneous_due`**：見上（H 門檻＋冷卻＋每段上限）。
  - **觀測**：`/status` 顯示「已確認 gate／原始 gate 連續幾拍／主動出聲就緒度（H、已伸手、冷卻剩）」。

## 怎麼看目前的參數與判定

- **`/status`**：一次看旋鈕（k 基準＋活力呼吸＝有效 k、心跳轉速）、**生命跡象**（🫀 活著／💀 死因、
  脈動數、連續健康圈、活了多久、單圈耗時）、以及最近一次背景判定的 Gate 與三條序參數（對照門檻）。
- **心跳轉速**＝環間等待秒數（`LIFELOOP_WAIT_SECS`，或在 bot 內 `/pulse 2` 即時調）。互動問狀態靠快取**秒回**。
